# PaperLens 8.2 分维度评分依据研究说明

更新时间：2026-08-21

状态：方案支撑材料，不直接修改最终方案正文。

## 1. 结论

现有八个评分维度总体有较充分的方法和领域依据，但必须区分两层：

1. **维度与指标形式有依据**：原子主张核验、事实支持率、引用准确性、引用完整性、方法与适用范围、结论与限制、术语与读者适配、风险与披露，都能在相关研究或官方规范中找到支持。
2. **具体数值没有统一标准**：现行表中的 `95%/85%/70%/50%`、各维度权重以及部分一票否决条件，不是上述文献规定的国际通行分界线，只能称为 PaperLens 的初始工程阈值，之后必须使用开发集校准并在保留集测试前冻结。

因此，最终方案宜把 8.2 定义为：

> 基于既有研究构建的分析型评分框架，客观维度报告原始比例，语义维度采用带行为锚点的 0 至 4 级量表；具体分档阈值由项目开发集校准，并在保留集评测前冻结。

## 2. 八个维度的依据映射

| PaperLens 维度 | 主要依据 | 能支持的设计 | 不能直接支持的内容 |
|---|---|---|---|
| 事实一致性 | [FActScore](https://arxiv.org/abs/2305.14251)、[RefChecker](https://arxiv.org/abs/2405.14486) | 将长文本拆成原子事实或细粒度主张，逐条判断是否被来源支持，再计算支持比例；RefChecker 还支持细粒度的主张核验 | 没有规定 `>=95%` 必须是 4 分，也没有规定关键主张权重必须为 2 |
| 引用准确性 | [ALCE](https://arxiv.org/abs/2305.14627)、[ResearchQA](https://arxiv.org/abs/2607.11074) | 将引用质量与正文流畅性、一般正确性分开评估；检查引用是否真实存在并实际支持对应陈述 | 没有给 PaperLens 的页码引用设定统一及格线；ResearchQA 是 2026 年预印本，宜作为补充证据而非唯一依据 |
| 引用完整性 | [ALCE](https://arxiv.org/abs/2305.14627)、[ResearchQA](https://arxiv.org/abs/2607.11074) | 单独测量需要证据的内容是否被引用覆盖，避免“引用本身正确，但大量关键主张没有引用” | 没有规定关键主张覆盖率 `90%/80%/60%/30%` 的五档边界 |
| 方法与适用范围 | [Generalization Bias in LLM Summarization of Scientific Research](https://arxiv.org/abs/2504.00025) | 科学摘要可能删除限定条件并把结论推广到原研究范围之外，因此应单独检查样本、方法、比较对象、推断范围和因果边界 | 不能推出当前五个关键字段具有同等权重，也不能推出 `90%` 是普适优良线 |
| 结论与限制完整性 | [PCORI plain-language summaries 实践研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8241231/)、[Plain language summaries 系统综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC9170105/) | 面向非专业读者的科研摘要通常需要保留研究缘由、方法、结果、限制和决策意义；结论与限制不应被一般事实支持率掩盖 | 这些研究主要来自健康和生物医学传播，只能作为方法类比，不能直接代表所有学科的统一模板 |
| 术语准确性 | [NIST TREC 2024 PLABA](https://pages.nist.gov/trec-browser/trec33/plaba/overview/)、PCORI 实践研究 | 通俗化包括术语替换或解释，但不能在改写中混入其他来源句的信息；可建立关键术语表并核验语境 | 不能只用句长或一个可读性公式代替术语语境正确性，也没有规定允许几个术语错误 |
| 读者适配与结构 | [NIST TREC 2024 PLABA](https://pages.nist.gov/trec-browser/trec33/plaba/overview/)、[Plain language summaries 系统综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC9170105/) | 应同时考虑可理解性、内容覆盖和信息忠实度；分句可以提升可读性，但不能跨原句混入信息 | 生物医学的 plain-language 标准不能原样当作“中国本科生”阅读标准；当前 5 项检查仍需结合项目目标定义 |
| 风险与合规 | [ICMJE AI 建议](https://www.icmje.org/recommendations/browse/artificial-intelligence/)、[人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm) | AI 内容需要人工负责准确性、引用、许可、保密和披露；符合适用情形的在线服务还涉及生成内容标识 | 本地比赛 demo 不等同于面向公众的网络服务，不能把所有网络服务义务不加判断地写成当前项目已适用的法定义务 |

## 3. 为什么可以使用 0 至 4 分，但不能宣称它是统一标准

[Jonsson 与 Svingby 的 rubric 研究综述](https://www.uidaho.edu/-/media/uidaho-responsive/files/provost/ir/assessment/assessment-resources/3e/scoring_rubrics_validity.pdf?la=en&rev=8b41d47cac334f01a63a5288f38d5dba)汇总了 75 项相关研究，结论是分析型、任务特定且配有示例的 rubric 更有利于提高评分一致性。但 rubric 本身不会自动保证有效性，仍需针对具体任务验证。

[G-Eval](https://aclanthology.org/2023.emnlp-main.153/)说明了用任务特定的评价标准、评价步骤和分级量表让 LLM 评估生成文本的可行性。[MT-Bench](https://arxiv.org/abs/2306.05685)同时指出 LLM 裁判存在位置、冗长偏好、自我偏好和推理局限。

由此可以支持以下设计：

- 使用分维度的分析型 rubric，而不是只让 Hy3 给一个模糊总分。
- 为每个等级写可观察的行为锚点、错误数量或覆盖比例。
- 让规则计算客观指标，让 Hy3 只处理必须依赖语义的判断。
- 固定 prompt、输入和模型参数，重复运行并检查顺序偏差。

但文献不要求必须使用 0 至 4。PaperLens 保留五级量表的合理理由是：它能表达“不可用、重大问题、需实质修订、仅需局部修订、达到目标”五种状态，并且 0 分可以自然表示硬失败。这个理由属于项目设计，不是引用文献得出的唯一选择。

建议统一五级含义：

| 等级 | 跨维度通用含义 |
|---|---|
| 4 | 达到目标，可直接使用，无实质性错误 |
| 3 | 基本可用，只需少量局部修订 |
| 2 | 存在实质问题，需要多处修改后复核 |
| 1 | 不可靠，需要大幅修订或重新生成 |
| 0 | 不可用，或触发预先定义的严重风险门槛 |

## 4. 建议的评分结构

### 4.1 原始指标是主结果

以下三维不应只显示 0 至 4 分：

- **事实一致性**：加权支持率、关键矛盾数、证据不足数。
- **引用准确性**：引用准确率、错误页码数、伪造引用数。
- **引用完整性**：关键主张引用覆盖率、未覆盖关键主张数。

评分等级只是便于用户快速阅读的界面结果，原始比例和错误清单必须同时展示。这也与 ResearchQA 发现“引用类指标比压缩后的 LLM 评价分更能区分系统”一致。

### 4.2 语义维度使用行为锚点

以下五维适合使用“检查项 + 严重错误 + 0 至 4 行为等级”：

- **方法与适用范围**：样本或对象、数据来源、研究方法、比较或基线、推断范围或因果边界。
- **结论与限制完整性**：主要结果覆盖、结论方向、关键限制、适用条件、不确定性。
- **术语准确性**：关键术语语境、首次解释、概念关系、缩写和单位。
- **读者适配与结构**：必要内容区、术语解释、段落主题、证据可定位、限定条件保留。
- **风险与合规**：来源与 AI 辅助说明、版权许可、敏感信息、身份冒充、学术欺骗和适用的生成内容标识。

Hy3 必须为每个扣分项返回：问题位置、判定理由、证据、严重度和建议，而不是只输出一个数字。

## 5. 当前阈值应该怎样处理

现行 `95/85/70/50` 等边界可以保留为开发阶段的候选值，但最终方案应改名为“初始阈值”，并采用以下校准流程：

1. 在方案既定的 10 篇开发集上，构造带已知错误标签的好、中、差输出。
2. 对每个输出保留注入错误类型、位置、严重度和预期质量等级。
3. 比较候选分界能否稳定区分三档，并重点检查严重错误的漏检和误报。
4. 根据开发集结果一次性确定阈值，在运行 20 篇保留集前冻结评分代码、prompt 和分界。
5. 保留集只用于报告结果，不再反向调分；未达到目标时如实说明，而不是继续移动阈值。
6. 同时报告原始指标、等级、置信区间、五次重复运行波动和典型失败案例。

## 6. 权重和硬门槛的表述

- “关键主张权重为 2、一般主张权重为 1”是风险导向的项目选择，不是 FActScore 的固定规定。需要在开发集做 `1:1` 与 `2:1` 的敏感性比较。
- 八维总分的权重也不是文献标准。应把八维向量和严重错误作为主要结果，加权总分只作次要概览。
- 伪造引用、关键数字或方向错误、因果关系反转、删除关键限制等可以设为硬门槛，因为它们会直接损害可核验性或改变论文含义。
- “出现一次即失败”仍属于 PaperLens 的产品风险策略，应明确写成项目验收规则，而不是外部研究规定。

如果等权和加权后的系统排序明显不同，最终报告应披露这种敏感性，不应只展示更好看的加权结果。

## 7. 最终方案建议增加的说明

最终统一修订时，8.2 前后应增加三项：

1. **评分依据表**：为八个维度逐项列出来源和适用边界。
2. **阈值来源说明**：明确区分文献支持的指标、开发集校准的分界、项目自定的硬门槛。
3. **评分卡示例**：展示一个主张如何从证据状态聚合到文档维度，并同时保留原始比例、错误清单和 0 至 4 等级。

推荐使用的严谨表述：

> 八维框架参考原子事实核验、引用质量评估、科学摘要通俗化和 AI 使用规范构建。文献用于确定评价对象和计算形式，不被用于虚构统一及格线。各分档阈值由开发集校准并在保留集评测前冻结；最终同时报告原始指标、分维度等级、硬失败项和稳定性结果。
